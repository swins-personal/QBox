## 시트

- `단어DB`: 열은 머리글 이름으로 찾는다. 앱이 쓰는 열: 단어ID, 단어, 뜻, 유사어·관련어, 변형·파생어, 예문, 예문 해석, 영역, 학습일, 손글씨 원문, 인지상태, 수정·학습 메모, 마지막 복습일, 다음 복습일, 복습 횟수, 이미지, 연상, 발음, 단어장, 주제.
- 단어장: `내 단어`(손글씨·사진·교재) 또는 `핵심어휘`(core-001~545). 빈칸이면 ID가 `core-`로 시작할 때만 핵심어휘.
- 새 단어는 맨 아래에 추가하면 된다. 이미지·연상·발음이 비어 있으면 앱이 Claude에게 물어 채우고 시트에 써 넣는다.
- `앱설정`: 시작일, 목표일, 하루 공부 시간(분), 하루 새 단어, 하루 복습 최대. 앱의 "플랜 설정" 팝업이 여기에 쓴다.

## 하루 학습 (오늘의 N분)

1. 복습: 다음 복습일이 오늘 이전인 단어, 최대 `하루 복습 최대`개. 문제 유형은 인지상태로 정한다: 0–3 그림·듣기·단어 고르기, 4–6 빈칸·같은 뜻·뜻 고르기, 7+ 쓰기·받아쓰기·말하기.
2. 새 단어: 내 단어(최근 학습일 먼저) → 핵심어휘(레벨 순). 5개씩 연상 카드로 배우고 바로 그림 맞추기·단어 고르기로 확인한다. 복습이 60개를 넘으면 새 단어 수를 줄인다.
3. 틀린 문제는 세션 끝에 한 번 더 나온다.

## 인지상태 규칙

- 처음 배움 = 1. 그림·객관식 정답 +1 (그림 최대 6, 객관식 최대 7), 쓰기·받아쓰기·말하기 정답 +2, 오답 −3, 스스로 체크 "알아요" +1 (최대 8).
- 다음 복습: 인지 0–10 → 1, 1, 1, 2, 2, 3, 4, 7, 10, 14, 30일. 8 이상이면 "외움".
- 기록은 10문제마다, 세션 끝, 화면을 떠날 때 묶어서 시트에 쓴다 (행 위치 확인 1회 + 일괄 쓰기 1회).

## 자유 연습

연상 카드, Listening(듣고 뜻 고르기·받아쓰기), Reading(예문 빈칸·같은 뜻), Writing(철자·예문 빈칸 쓰기), Speaking(그림 보고 말하기; 크롬에서는 음성 인식으로 채점).
